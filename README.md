# wordle

MacOS install command:
```mkdir wordle && cd wordle && xcode-select --install && git clone https://github.com/subtlePanzer/wordle.py && cd wordle.py && python3 -m venv venv && source venv/bin/activate && pip install -r requirements.txt && pip install pyinstaller && pyinstaller --onefile wordle.py && chmod +x dist/wordle```
